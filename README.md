===========
I added four essential arguments into the script using the argparse library: scale, scale_nature, nature_position, and panda_jogging. The scale option allows the user to set the image's scaling factor, which determines whether the image is enlarged or shrunk. The scale_nature argument allows the user to specify the type of scaling, selecting 'up' for upscaling and 'down' for downscaling. The nature_position option accepts a tuple of two numbers defining the horizontal and vertical position for exact control over the position of the scaled image.The panda_jogging option, a boolean value, turns on or off the jogging effect. An optional no_rotate flag can also be specified to avoid image rotation during scaling.When altering and scaling images within the script, this combination of arguments enables flexibility and customization.
