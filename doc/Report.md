As a beginner in programming languages,I've witnessed a significant change in how I approach the materials i have been provided to use when coding, mainly because of the major development of tools and technologies given. This report goes through five crucial tools and how they've influenced my experiences. I'll talk about my little experience to tools I've used in the past and briefly explain how the new tools have developed my learning process.

IDE,or Integrated development environment,was introduced to me during my earlier studies at King Saud University and Newcastle University. As a beginner, I started with IDLE, which is an excellent choice for learning the Python language, then I used sublime, and finally, I was introduced to PyCharm. After a while, I concluded that this type of IDE is the best to work with since it is well-featured, pleasant, and simple to use, and the underlying IDE supports development in the majority of the languages you are probably going to use. I was also familiar with GitHub and JetBrains, where you must establish accounts and connect them to your Pycharm IDE. As a result of this, I didn't face major issues in the first tool.

As for the second tool which is Markdown,it's mainly used for documentation especially in crafting README files and project documentation. It can be converted into many other formats include PDF and HTML. After using this tool for a while it have proven to be a useful resource for writing clear and well-structured documentation that is both easy to share and maintain. I really prefer using this tool instead of documenting projects in  a simple text which could be boring to read.

Moving on to the third tool,version control,specifically Git, has quickly become an essential part of my code and programs. It allows me to keep track of modifications, communicate with others, and keep a complete history of the source. It has already proved beneficial in keeping my coding tasks organized and efficient. This tool was quite useful in this practical; where it was extremely helpful that I was familiar with git in my earlier studies.

The 4th tool,Dependency Management and Isolation,was completely new to me. This tool has really enhanced and expanded my skills in general, as well as in this Panda project to be specific. I used numerous dependency management technologies, such as: npm, wheel, egg setuptools, pip, Maven, and venv, to manage project dependencies and maintain consistency across multiple development and deployment environments. In this project, we used pip and venv dependency managments. Pip utilizes a file called requirements.txt, where we added a dependency called panda3d.

Finally, my knowledge of the last key tool,Real-Time Monitoring (RTM), was limited; I had looked into RTM more when I began working on the Panda project. It provides immediate insights, increasing my learning process with faster issue detection and feedback. I can see how, as I continue getting used to newer tools, they will greatly improve my software development skills and my journey as a beginner.
